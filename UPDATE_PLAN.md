# Автообновления KeyDeck

Релиз создаётся GitHub Actions при отправке тега `vX.Y.Z`. Каждый релиз содержит один исполняемый файл `KeyDeck-vX.Y.Z.exe` и `SHA256SUMS.txt`.

1. KeyDeck асинхронно проверяет GitHub API при запуске или по команде из меню трея.
2. При наличии более новой стабильной версии приложение спрашивает пользователя, устанавливать ли её.
3. Новая сборка загружается во временную папку; перед запуском сверяется SHA-256 и сигнатура Windows EXE.
4. Отдельный временный updater ждёт завершения KeyDeck, атомарно заменяет только EXE, запускает обновлённую версию и удаляет резервную копию.
5. При сбое замены предыдущая версия восстанавливается и запускается повторно.
6. Конфигурация и состояние плагинов находятся в `%LOCALAPPDATA%\KeyDeck`, поэтому обновление бинарного файла их не затрагивает. При первом запуске EXE прежние настройки рядом с программой мигрируют в эту папку.

Обновлятор обращается только к релизам `Scworch/KeyDeck`, не исполняет команды или скрипты из GitHub и ограничивает размер скачиваемого файла.
