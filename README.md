# KeyDeck

KeyDeck — приложение для Windows, превращающее рабочий стол в настраиваемую панель быстрого доступа, похожую на Stream Deck.

- компактное окно и значок в системном трее;
- сетка показывает только назначенные кнопки и автоматически уплотняет их; несколько страниц переключаются колёсиком мыши;
- назначение действий и сочетаний клавиш на кнопки;
- общие вкладки настроек плагина, действия кнопки и Button Appearance;
- уведомление о новых версиях и обновление прямо из приложения.

## Установка для пользователей

1. Откройте [последний релиз KeyDeck](https://github.com/Scworch/KeyDeck/releases/latest).
2. Скачайте файл `KeyDeck-vX.Y.Z.exe` и сохраните его в постоянную папку, например:
   `%LOCALAPPDATA%\Programs\KeyDeck\KeyDeck.exe`.
3. Запустите `KeyDeck.exe`. По умолчанию запуск с правами администратора не требуется; включить его можно в настройках системы.

Для использования релизной версии Python и отдельная установка зависимостей не нужны. Не запускайте программу прямо из временной папки загрузок: обновление заменяет EXE по его текущему пути.

Windows Defender SmartScreen может показать предупреждение, так как релиз пока не подписан цифровым сертификатом. Перед запуском проверяйте источник загрузки и SHA-256 в `SHA256SUMS.txt`, приложенном к релизу.

### Настройки и обновления

Исполняемый файл находится в выбранной вами папке, а пользовательские данные — отдельно:

- `%LOCALAPPDATA%\KeyDeck\config\settings.json` — конфигурация панели;
- `%LOCALAPPDATA%\KeyDeck\plugins\` — настройки и кэши плагинов;
- `%LOCALAPPDATA%\KeyDeck\installed_plugins\` — отдельно установленные файлы плагинов;
- `%LOCALAPPDATA%\KeyDeck\plugin_backups\` — предыдущая версия для отката.

Обновление заменяет EXE по текущему пути, сохраняя его имя и не затрагивая пользовательские данные; при этом обновляется и иконка файла. Перед установкой новая версия скачивается во временную папку, а при ошибке замены восстанавливается предыдущий EXE. Автоматическая проверка выполняется не чаще одного раза в 24 часа. В настройках → **Updates** отображаются установленная и доступная версии, оттуда же можно вручную проверить и установить обновление. Проверка также доступна через меню значка в трее → **Check for Updates**.

### Удаление приложения

В релизной версии откройте настройки → **System** → **Uninstall KeyDeck**. Удаление закрывает приложение, убирает его EXE, задачу автозапуска и стандартные ярлыки. В подтверждении можно оставить включённой галочку **Keep settings, plugin data, installed plugins, and backups** — тогда данные в `%LOCALAPPDATA%\KeyDeck` сохранятся для будущей установки. Если снять галочку, эта папка со всеми настройками панели и плагинов, кэшами, установленными плагинами и резервными копиями будет удалена.

Релизные сборки рассчитаны на Windows x64. Они собираются из исходников проекта GitHub Actions при публикации тега `vX.Y.Z`.

### Свой заголовок и значок кнопки

Назначьте действие кнопке на странице **Button layout**, затем откройте **Settings → Plugins → Button Appearance**. Для кнопки можно задать заголовок, изображение, режим **Fill / Fit / Crop**, масштаб и смещение значка. Пустой заголовок и кнопка **Clear** возвращают значения плагина по умолчанию. Выбранный файл значка остаётся по исходному пути — не перемещайте и не удаляйте его.

## Ярлык на рабочем столе

Замените путь, если установили EXE в другую папку, и выполните в PowerShell:

```powershell
$exe = Join-Path $env:LOCALAPPDATA 'Programs\KeyDeck\KeyDeck.exe'
$shortcut = (New-Object -ComObject WScript.Shell).CreateShortcut(
    (Join-Path $env:USERPROFILE 'Desktop\KeyDeck.lnk')
)
$shortcut.TargetPath = $exe
$shortcut.WorkingDirectory = Split-Path $exe
$shortcut.Save()
```

Для ярлыка в меню «Пуск» используйте путь `%APPDATA%\Microsoft\Windows\Start Menu\Programs\KeyDeck.lnk`.

## Запуск через Task Scheduler

В настройках системы можно включить автозапуск через задание `KeyDeck_AutoStart` и отдельно выбрать постоянный запуск от имени администратора. Нажмите **Create / update startup task**, чтобы сразу зарегистрировать задачу или восстановить отсутствующую. Если Windows потребует повышенные права, приложение предложит перезапуститься от имени администратора. Для ручного создания задачи запустите PowerShell от имени администратора, проверьте путь к EXE и выполните:

```powershell
$exe = Join-Path $env:LOCALAPPDATA 'Programs\KeyDeck\KeyDeck.exe'
$action = New-ScheduledTaskAction -Execute $exe -WorkingDirectory (Split-Path $exe)
$user = [System.Security.Principal.WindowsIdentity]::GetCurrent().Name
$trigger = New-ScheduledTaskTrigger -AtLogOn -User $user
$principal = New-ScheduledTaskPrincipal -UserId $user -LogonType Interactive -RunLevel Highest
$settings = New-ScheduledTaskSettingsSet -MultipleInstances IgnoreNew `
    -ExecutionTimeLimit ([TimeSpan]::Zero)
Register-ScheduledTask -TaskName 'KeyDeck' -Action $action -Trigger $trigger `
    -Principal $principal -Settings $settings -Force
```

Удалить задачу:

```powershell
Unregister-ScheduledTask -TaskName 'KeyDeck' -Confirm:$false
```

Для запуска приложения достаточно войти в свою учётную запись Windows; не выбирайте запуск без входа пользователя, так как KeyDeck использует интерактивный рабочий стол и системный трей.

## Установка из исходников

Для разработки или запуска без готового релизного EXE установите Python 3.11+ и выполните в корне репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m keydeck
```

Сборка Windows EXE локально:

```powershell
python -m pip install -r requirements-build.txt
python scripts\build_executable.py
```

Сборка создаёт `dist\KeyDeck.exe` из файлов проекта, исключая игнорируемые локальные настройки и кэши. Автоматическое обновление заменяет только релизный EXE; запуск из исходников покажет страницу релиза, откуда можно скачать готовую сборку.

## Плагины и совместимость

В релизной сборке находится только Core и каталог метаданных. Откройте настройки → **Plugins** → **Plugin Library**, чтобы отдельно скачать нужный плагин. В библиотеке доступны поиск, описание, версия, совместимость и заявленные возможности плагина; там же можно установить, обновить, удалить или откатить его. Для установки и каждого обновления требуется явное подтверждение.

Исходный код и манифесты плагинов для разработки находятся в `plugins/<plugin_id>/`; каталог `plugins/catalog.json` описывает доступные версии. Каждый плагин публикуется отдельным архивом и GitHub Release, независимо от версии Core. После обновления старой версии KeyDeck назначения кнопок сохраняются; если код назначенного плагина ещё не установлен, приложение предложит установить его из библиотеки. Удаление плагина не затрагивает его настройки, кэш и сохранённые назначения.

Один плагин можно назначить только одной кнопке на всех страницах; нужный профиль, канал или действие выбирается во вкладке **Button** в настройках плагина. Вкладка **Button Appearance** задаёт оформление этой кнопки.

SHA-256 проверяется до установки, архив ограничен по размеру и безопасно распаковывается во временную папку. Версия и совместимость из манифеста сверяются с каталогом; установка выполняется атомарно, предыдущую версию можно восстановить через **Roll back**.

Заявленные разрешения показывают, какие возможности использует плагин, но Python-код не запускается в песочнице и может использовать все права текущей учётной записи Windows. Не устанавливайте плагины, которым не доверяете. См. [план дальнейшего развития и ограничения безопасности](PLUGIN_PLAN.md).

WQS остаётся экспериментальным исходным кодом и пока не включён в каталог доступных плагинов.

В настройках → **Plugins** можно отключить любой установленный плагин. После сохранения KeyDeck останавливает его через `stop()`, удаляет его действия и выгружает модуль; назначения кнопок и файлы настроек плагина сохраняются и возвращаются при повторном включении.

- **MultiTool** выполняет на одной кнопке упорядоченную последовательность программ, ссылок, команд, действий любых установленных плагинов и задержек. Каждый плагин в последовательности имеет собственные настройки; шаги можно отключать, редактировать и перемещать.
- **Steam Launcher** запускает выбранный Steam-профиль или игру с параметрами запуска; профиль выбирается в настройках назначенной кнопки.
- **Discord Connect** управляет голосовым каналом, Mute и Deafen в Discord Desktop через локальный IPC.
- **ResolutionSwitcher** меняет разрешение через стандартный Windows Display API. Целевой режим должен поддерживаться монитором и драйвером.
- **NVIDIA RTX Video Super Resolution** использует NVIDIA NvCpl API. Ему необходимы поддерживаемая RTX-видеокарта, совместимый драйвер и установленное приложение NVIDIA App. На ПК без подходящего оборудования эта функция недоступна; другие плагины KeyDeck продолжат работать.
- **Wave Link** требует установленного Wave Link и совместимого .NET Framework runtime; для перенаправления аудио дополнительно используется Windows COM audio API.

Shortcut Launcher удалён: его запуск программ, ссылок и Windows-команд доступен в MultiTool. При обновлении Core установленная копия Shortcut Launcher будет удалена; настройки и данные плагина останутся на диске.

Варианты значков приложения и трея находятся в `assets/icon_candidates/`; контактные листы `exe-options.png` и `tray-options.png` позволяют сравнить по пять вариантов. Для EXE выбрана иконка **Grid 1**; текущий значок трея оставлен без изменений.

## Данные и конфиденциальность

Настройки слотов, параметры плагинов и кэши остаются на компьютере пользователя. Они не входят в релизный EXE и не удаляются при обновлении. Файл `.gitignore` исключает локальные настройки и кэши плагинов из Git.
